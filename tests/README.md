# Test audio

- `jfk.wav` is an 11-second clip of President Kennedy's 1961 inaugural address, a
  public-domain US government recording (copied from the whisper.cpp samples).
- `long.mp3` is the same clip repeated eight times as a stereo MP3.
- `dialogue.mp3` is a **made-up** two-person practice conversation spoken by computer
  voices (Piper text-to-speech: "Southern English Female" and "Alan"), generated by
  `scripts/make-test-dialogue.py`. `dialogue.json` lists who speaks when. It is used to
  check speaker labels. No real person or session is involved.

**Never put real recordings in this folder or anywhere in this repository.**
